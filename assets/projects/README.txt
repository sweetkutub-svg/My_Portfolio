PROJECT IMAGES
==============
Each project has its own folder. Put 2 PNG images in it (exact names):

  cover.png    -> main screenshot, 16:9 landscape (best 1600x900)
  preview.png  -> second screenshot (best 1280x720)

Folders:
  assets/projects/maison-store/          MAISON Store           (done)
  assets/projects/mondol-restaurant/     Mondol Restaurant      (done)
  assets/projects/raos-restaurant/       Rao's Restaurant       (done)
  assets/projects/imli-mix/              Imli Mix               (add cover.png + preview.png)
  assets/projects/nova-voice-assistant/  Nova AI Voice Assistant (add cover.png + preview.png)

If an image is missing, a neutral placeholder card is shown.
